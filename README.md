# fbforcar

บอท Selenium สำหรับลงโฆษณาเช่ารถไฟฟ้า BYD Dolphin ในกลุ่ม Facebook มี 2 โปรแกรม

| โฟลเดอร์ | ทำอะไร | วิธีเปิด |
|---|---|---|
| `bot-facebook-master/` | เมนูในหน้าจอดำ: โพสต์ในกลุ่ม, คอมเมนต์ในกลุ่ม, ค้นหาแล้วคอมเมนต์ และหากลุ่มใหม่ (`find_groups.py`) | `python index.py` |
| `bot-facebook-auto-comment/` | หน้าต่างโปรแกรม: คอมเมนต์หรือโพสต์ตามลิงก์ใน `config.xlsx` | `python app.py` |
| `bot-facebook-master/chat_bot.py` | บอทตอบแชตลูกค้าใน "คำขอส่งข้อความ" และกดยืนยันคำขอเป็นเพื่อนใหม่ | ดับเบิลคลิก `run_chat_bot.bat` |

## บอทตอบแชต (`chat_bot.py`)

- ทุก 2–4 นาที ดู "คำขอส่งข้อความ" แชตที่ทักมาภายใน 24 ชม. และ**ยังไม่มีใครตอบ** จะได้ข้อความใน `chat_reply.xlsx` 1 ครั้ง ข้อความบอกลูกค้าว่าเป็นข้อความอัตโนมัติ และแอดมินจะตอบต่อ
- ถ้าตอบเองทางมือถือไปแล้ว บอทจะไม่ยุ่งกับแชตนั้น และไม่ตอบแชตปกติในกล่องข้อความของเพื่อน
- ทุก 30 นาที กด "ยืนยัน" คำขอเป็นเพื่อนที่ส่งมาไม่ถึง 1 เดือน (ครั้งละไม่เกิน 10 คน) คำขอเก่าไม่แตะ
- **ครั้งแรกต้องใส่ PIN แชต Messenger เองในหน้าต่าง Chrome ของบอท** เพราะแชตเข้ารหัส บอทมีโปรไฟล์ Chrome ของตัวเองที่ `%LOCALAPPDATA%\bot-facebook-master\chat-profile` จึงจำ PIN ไว้ ครั้งต่อไปไม่ต้องใส่ ห้ามกด "อย่ากู้คืนข้อความ"
- ลองดูก่อนได้ด้วย `run_chat_bot.bat --dry` (ไม่ส่ง ไม่กด แค่บอกว่าจะทำอะไร)
- แก้ข้อความตอบได้ใน `chat_reply.xlsx` ช่อง A2 ห้ามมีวงเล็บ `[ ]` ค้าง บอทจะไม่ยอมเริ่ม
- แชตที่ตอบแล้วอยู่ใน `chat_history.txt` เพื่อนที่กดยืนยันแล้วอยู่ใน `friend_history.txt` (ไม่ขึ้น git)

## บอทอัตโนมัติ (`autopilot.py`) ทำงานเองตามเวลา ไม่ต้องเปิด Claude

| งาน | เวลา | ทำอะไร |
|---|---|---|
| `autopilot.py daily` | ทุกวัน 09:07 | เข้ากลุ่มใหม่จาก `groups_found.xlsx` วันละไม่เกิน 5 กลุ่ม (ไม่ตอบคำถามก่อนเข้ากลุ่ม) เช็กกลุ่มที่รออนุมัติ แล้วโพสต์ 1 ครั้งต่อกลุ่มต่อวัน |
| `autopilot.py comments` | 10:23 12:23 14:23 16:23 18:23 20:23 | หาโพสต์คนหารถในกลุ่ม แล้วคอมเมนต์พร้อมรูป รอบละไม่เกิน 4 วันละไม่เกิน 15 ไม่คอมเมนต์คนเดิมซ้ำใน 3 วัน |

- ตั้งเวลาครั้งเดียว: `powershell -ExecutionPolicy Bypass -File bot-facebook-master\setup_autopilot.ps1` (เอาออก: เติม `-Remove`)
- **ต้องเสียบสายชาร์จไว้ และกด Sleep แทนการ Shut down** เครื่องจะตื่นมาทำงานเองตามเวลา ถ้าปิดเครื่องไว้ จะทำงานทันทีเมื่อเปิดเครื่องครั้งถัดไป
- ห้าม Sign out จาก Windows (ล็อกจอได้)
- เลือกโพสต์ที่จะคอมเมนต์ด้วย `services/seeker_rules.py` ตั้งไว้เข้ม: ข้ามโฆษณาร้านอื่นและเต็นท์รถ, งบต่ำกว่า 900/วัน หรือ 20,000/เดือน, รถ 7 ที่นั่ง/รถตู้/กระบะ/รถหรู, รับรถไกลจาก กทม., รายเดือนสั้นกว่า 6 เดือน
- ลองก่อนได้: `run_autopilot.bat comments --dry` (หาและบอกว่าจะคอมเมนต์ใคร แต่ไม่คอมเมนต์จริง)
- log ทุกวันอยู่ที่ `%LOCALAPPDATA%\bot-facebook-master\autopilot\logs\` ถ้า cookies หมดอายุหรือ Facebook ขึ้นเตือน บอทจะหยุดและเขียนบอกไว้ในนั้น (cookies หมดอายุ: เปิด `index.py` ล็อกอินใหม่ 1 ครั้ง)

## ติดตั้ง (Windows)

1. ลง Python 3.13 และ Google Chrome
2. ในแต่ละโฟลเดอร์ รัน `pip install -r requirements.txt`
3. ไม่ต้องหา chromedriver เอง Selenium จะโหลดตัวที่ตรงกับ Chrome ในเครื่องให้อัตโนมัติ

## ล็อกอิน

- เปิดโปรแกรมครั้งแรก จะมีหน้าต่าง Chrome ขึ้นมาให้ล็อกอิน Facebook เอง (รวมถึงยืนยันตัวตนหรือ 2FA) โปรแกรมจะไปต่อเองเมื่อเข้าหน้าแรกได้
- cookies จะถูกเข้ารหัสด้วย Windows แล้วเก็บไว้ที่ `%LOCALAPPDATA%\bot-facebook-master\` และ `%LOCALAPPDATA%\bot-facebook-auto-comment\` ไม่อยู่ในโฟลเดอร์นี้ ไม่ขึ้น git และใช้ได้เฉพาะบัญชี Windows ที่สร้างมันเท่านั้น
- ตั้งภาษา Facebook ของบัญชีเป็น **ภาษาไทย** เพราะบอทหาปุ่มจากข้อความภาษาไทย

## ตั้งค่าใน Excel

- `bot-facebook-master/setting.xlsx` มี 1 ชีตต่อ 1 เมนู ชีต "โพสต์ในกลุ่ม" คือรายชื่อกลุ่มที่จะโพสต์
- `bot-facebook-auto-comment/config.xlsx` มีคอลัมน์ `action` (comment / post), `comment`, `url`, `image`
- **ข้อความหลายแบบ:** ใส่หลายแบบในช่องเดียวได้ โดยคั่นด้วยบรรทัดที่มีแค่ `---` บอทจะสุ่มใช้ทีละแบบ
- **ข้อความคอมเมนต์ต้องเป็นบรรทัดเดียว** เพราะกด Enter แล้วส่งทันที ส่วนข้อความโพสต์ขึ้นบรรทัดใหม่ได้
- **รูป:** ช่องรูปใส่ `-` ถ้าไม่ใช้รูป หรือใส่ path ของรูป เช่น `images\imp_post_4x5.jpg` (นับจากโฟลเดอร์โปรแกรม) หรือ path เต็ม
  - หลายรูปในโพสต์เดียว คั่นด้วย `,`
  - หลายชุดให้สุ่มใช้ทีละชุด คั่นด้วยบรรทัด `---` เหมือนช่องข้อความ
  - คอมเมนต์ใส่ได้ 1 รูป ถ้าใส่หลายรูป บอทใช้รูปแรก
  - ตั้งไว้ตอนนี้: โพสต์สุ่มใช้โปสเตอร์ 4:5 หรือ 1:1 ทีละ 1 รูป (เป็นภาพเดียวกันคนละขนาด) คอมเมนต์ใช้ 1:1
- ไม่ใส่ลิงก์เว็บในข้อความโพสต์และคอมเมนต์ (เจ้าของร้านเลือกเอง) ลูกค้าสแกน QR ในโปสเตอร์เพื่อเข้าเว็บจอง https://impcar.vercel.app ได้

## กติกา (กันบัญชีโดนแบน)

- บอทเว้นระยะ 1.5–3 นาทีระหว่างแต่ละกลุ่มหรือแต่ละคอมเมนต์อยู่แล้ว อย่าลดลง
- โพสต์กลุ่มเดิมไม่เกินวันละครั้ง และเข้ากลุ่มใหม่ไม่เกินวันละ 5–10 กลุ่ม
- คอมเมนต์เฉพาะโพสต์ของคนที่**กำลังหารถเช่า** ไม่คอมเมนต์ใต้โพสต์ของร้านอื่น
- auto-comment จำโพสต์ที่คอมเมนต์ไปแล้วใน `commented_history.txt` และจะไม่คอมเมนต์ซ้ำ
- **ห้าม commit ไฟล์รหัสผ่าน (.csv) หรือ cookies** ไฟล์ `.gitignore` กันไว้ให้แล้ว
- ใช้บัญชีจริงบัญชีเดียว ไม่หมุนหลายบัญชีมาโพสต์โฆษณาเดียวกัน
