# Bot Auto Comment

📌 **Bot Auto Comment** เป็นโปรแกรมอัตโนมัติที่ใช้ Selenium เพื่อค้นหาและคอมเมนต์ในโพสต์ของ Facebook ตามเงื่อนไขที่กำหนด

## 🔧 วิธีติดตั้ง

### 1. ติดตั้ง Python และ Dependencies

**ต้องใช้ Python 3.x**  
ติดตั้ง dependencies ที่จำเป็นโดยรัน:

```sh
pip install -r requirements.txt
```

## 🚀 วิธีใช้งาน

### 1. รันโปรแกรม

```sh
python index.py
```

### 2. เลือกโหมดการทำงาน

เมื่อรันโปรแกรม จะมีตัวเลือกให้ใช้งาน:

- **1.1** ค้นหาโพสต์จากหัวข้อ แล้วคอมเมนต์ (เลือกเฉพาะโพสต์ล่าสุด)
- **1.2** ค้นหาโพสต์จากหัวข้อ แล้วคอมเมนต์ (ผลค้นหาปกติ)
- **2.1** คอมเมนต์ในกลุ่ม (เรียงโพสต์ล่าสุดก่อน)
- **2.2** คอมเมนต์ในกลุ่ม (ลำดับปกติของกลุ่ม)
- **3** คอมเมนต์ในกลุ่มขั้นสูง (กรองโพสต์ด้วยคำที่ต้องการ/ไม่ต้องการ)
- **4** คอมเมนต์ในโพสต์ที่กำหนด
- **5** โพสต์ในกลุ่ม

หลังจากเลือกโหมดแล้ว โปรแกรมจะเริ่มทำงานอัตโนมัติ

ครั้งแรกจะเปิด Chrome ให้ล็อกอิน Facebook เอง ล็อกอินเสร็จแล้วโปรแกรมจะไปต่อเองและจำการล็อกอินไว้ใช้ครั้งต่อไป

🔒 ข้อมูลล็อกอิน (cookies) เก็บไว้ที่ `%LOCALAPPDATA%\bot-facebook-master\facebook_cookies.dat` ในเครื่องนี้เท่านั้น ไม่อยู่ในโฟลเดอร์โปรเจกต์และไม่ซิงก์ขึ้น OneDrive ไฟล์ถูกเข้ารหัสด้วย Windows (DPAPI) เปิดได้เฉพาะบัญชี Windows นี้บนเครื่องนี้ ถ้าต้องการออกจากระบบหรือเปลี่ยนบัญชี ให้ลบไฟล์นี้แล้วรันใหม่

### 3. ตั้งค่าใน `setting.xlsx`

- **รูปภาพ**: ใส่ path เต็ม เช่น `C:\Users\ชื่อ\Pictures\a.png` หรือชื่อไฟล์ที่วางไว้ในโฟลเดอร์โปรแกรม เช่น `test.png` ถ้าไม่ใช้รูปให้ใส่ `-`
  - ชีต "โพสต์ในกลุ่ม" ใส่หลายรูปคั่นด้วย `,`
  - ชีต "คอมเมนต์ในกลุ่มadvance" ใส่หลายรูป/หลายคอมเมนต์คั่นด้วย `||`
- **จำนวนคอมเมนต์**: คอมเมนต์เฉพาะโพสต์ที่มีคนคอมเมนต์อยู่แล้วอย่างน้อยเท่านี้
- **จำนวนครั้ง**: จำนวนโพสต์ที่จะคอมเมนต์ (ถ้าเลื่อนหา 30 ครั้งไม่เจอโพสต์ใหม่จะหยุดเอง)
- Facebook ต้องตั้งเป็น**ภาษาไทย** เพราะโปรแกรมหาปุ่มจากข้อความภาษาไทย

## ⚙ การสร้างไฟล์ `.exe`

หากต้องการแปลงโปรแกรมเป็นไฟล์ `.exe` ให้ใช้คำสั่งนี้:

```sh
pyinstaller --onefile --add-data "services;services" --add-data "utils;utils" --name "Bot Auto Comment" index.py
```

ไฟล์ `.exe` จะถูกสร้างในโฟลเดอร์ `dist/` ให้วาง `setting.xlsx` (และไฟล์รูป) ไว้ในโฟลเดอร์เดียวกับ `.exe`

## 🚑 หยุดการทำงาน

หากต้องการหยุดโปรแกรม สามารถกด **Ctrl + C**
